# Curso Python do Zero ao Avançado

Repositório com exercícios e práticas desenvolvidos durante meus estudos de Python em um curso profissionalizante, acompanhando minha evolução desde os fundamentos até conteúdos mais avançados.

## Objetivo

Registrar minha evolução na linguagem Python por meio de exercícios práticos realizados ao longo do curso.

## Conteúdos praticados

- Lógica de programação
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Laços de repetição
- Listas, tuplas, conjuntos e dicionários
- Funções
- Funções lambda
- Módulos e pacotes
- Manipulação de arquivos
- JSON
- Programação Orientada a Objetos
- Tratamento de erros
- Organização e reutilização de código

## Organização

Os arquivos estão organizados de acordo com a sequência das aulas do curso, permitindo acompanhar minha evolução ao longo dos estudos.

## Curso de referência

Curso Python 3 do Zero ao Avançado, realizado pela plataforma Udemy.
